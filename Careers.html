Careers in the Database Ecosystem

Database knowledge can support different technology careers involving data management, software systems, infrastructure and analytics.

Career Opportunities

Database Administrator

Database administrators help organisations manage database systems, including performance, access, availability, backup and maintenance.

Relevant Skills

  • SQL
  • Database management
  • Security
  • Backup and recovery

Data Engineer

Data engineers work with systems and pipelines that collect, transform, store and make data available for analysis and applications.

Relevant Skills

  • SQL
  • Programming
  • Data pipelines
  • Cloud technologies

Database Developer

Database developers design and develop database structures, queries, procedures and data-related components for software applications.

Relevant Skills

  • SQL
  • Database design
  • Programming
  • Application development
